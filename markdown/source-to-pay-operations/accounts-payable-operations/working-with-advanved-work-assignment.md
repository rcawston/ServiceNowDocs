# Working with Advanced Work Assignment

Suppliers interact with APO agents for invoice inquiry cases using the live chat.

## Before you begin

Role required: admin

## Procedure

1.  Navigate to **All** &gt; **Supplier Collaboration portal**.

    Suppliers interact with APO live agent for invoice inquiry cases. The interactions between supplier and APO live agent is recorded in an auto-generated interaction record. For more information regarding interaction record, refer [Interaction management in Accounts Payable Operations](interaction-record.md).

2.  Click **Create a case** through the interaction record to create an inquiry case.

    For more information about invoice case, refer [Create New Invoice case form](create-new-ap-case-form.md).
